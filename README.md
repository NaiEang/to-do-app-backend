# Full-Stack Todo App

A full-stack Todo application with a NestJS backend and a React (Vite) frontend.

## Project Structure

- `backend/` - NestJS REST API (`http://localhost:3000/api/todos`)
- `frontend/` - React + Vite UI (`http://localhost:5173`)

## Getting Started

### 1. Backend Setup
```bash
cd backend
npm install
npm run start:dev
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
